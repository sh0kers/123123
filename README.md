# HolyWorld TNT Builder (Fabric 1.21.4)

Клиентский мод. По одной кнопке (по умолчанию **G**, меняется в Управление -> HolyWorld) делает весь цикл:

1. берёт **Тнт-Пушку** (раздатчик с таким названием) и ставит туда, куда смотрит прицел;
2. открывает пушку и шифт-кликом кладёт туда **Динамит B**;
3. ставит рядом с пушкой **редстоун блок**;
4. ждёт, пока динамит в пушке закончится (раз в несколько секунд открывает её и проверяет);
5. ломает пушку **киркой** (и потом редстоун блок, чтобы вернуть его).

Повторное нажатие кнопки во время работы - остановка. Ошибки пишутся в чат.

## Как пользоваться
- Тнт-Пушка, Динамит B, редстоун блок и кирка должны быть в инвентаре (хотбар или основной).
- Наведи прицел на блок, куда ставить пушку, **не зажимай Shift**, нажми G.
- Пушка стреляет в сторону, куда её "развернула" установка (как у обычного раздатчика - лицом к игроку), поэтому встань так, чтобы дуло смотрело куда нужно.
- Удали старый jar (`HolyWorld-TNT-Builder-...jar`) из mods, иначе будет конфликт (тот же id мода).
- Нужны Fabric Loader 0.16.9+, Fabric API, Java 21.

## Настройки
Файл `.minecraft/config/holyworld-tntbuilder.json` (создаётся при первом запуске):
- `cannonName`, `tntName` - часть названия предметов (регистр не важен, русская В = латинская B);
- `waitForEmpty` - ждать, пока динамит кончится (true) или просто `fixedWaitSeconds` секунд (false);
- `maxWaitSeconds` - максимум ожидания, потом пушка ломается всё равно;
- `pollSeconds` - как часто проверять содержимое пушки;
- `breakRedstoneBlock` - ломать ли редстоун блок после пушки;
- `actionDelayTicks`, `clickDelayTicks` - паузы (если сервер кикает за скорость - увеличь).

## Сборка
Нужны JDK 21 и Gradle 8.12.

**Вариант 1 - без установки чего-либо (GitHub):**
1. Создай репозиторий на github.com и загрузи в него все файлы этой папки (включая скрытую `.github`).
2. Вкладка Actions -> build -> Run workflow (или просто сделай commit).
3. Скачай артефакт `holyworld-tnt-builder`, внутри возьми jar **без** `-sources` в названии.

**Вариант 2 - локально:** `gradle build`, jar появится в `build/libs/`.
(Если у тебя есть проект-шаблон с https://fabricmc.net/develop - можно положить `src/` и `build.gradle` туда и запустить `./gradlew build`.)
